# 初始测试用例登记

日期：2026-10-17。需求基线：[miniapp_plan.md](../miniapp_plan.md)。

状态：`待决策`=预期依赖用户决定；`待实现`=用例已设计但没有产品实现或执行证据；`通过/失败/阻塞`必须绑定执行记录。下表不是已通过报告。后续每次开发补用例、脚本位置与执行结果；发现缺陷需增加可复现回归用例，不能只改状态。

通用字段：测试ID、需求/决策ID、优先级、环境/fixture版本、前置条件、步骤、预期、自动化位置、执行日期、提交SHA、结果、证据、缺陷ID。新代码落地后将“自动化位置”补为真实路径；本轮不编造脚本存在。

优先级：P0阻断核心闭环/数据正确性；P1主要功能或恢复；P2展示完善。自动化层：U单元、I接口/数据库集成、E后台/H5场景端到端、V视觉、W微信真实环境。
