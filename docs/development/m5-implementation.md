# M5实现约束（开发中）

依据主计划M5/M6、MT059–114及D03/D04/D06执行；不增加登录、作品提交或额外测评。

- 同访客/场景/任务只建一份计划，重复选择复用；首次来源不可变，岗位来源必须为本人已成功且已选择该方向的分析。
- 同计划同时仅一个未提交测验，以计划行锁串行创建；重测递增sequence，旧题目快照、答案、成绩保留。草稿响应不含正确答案和解释；提交后才能回顾。
- 草稿、等级与位置使用revision防旧覆盖；提交使用持久幂等键。服务端按固定mock-score-v1评分，0/1初阶、2/3进阶、4高阶。首次默认推荐等级，重测保留已存在的自主选择；新推荐与历史结果分开呈现。
- 依据产品手册第5节的明确口径，同访客/课程的看过标记和播放秒数共享；D06的“任务独立继续位置”落实为该任务最近访问的课程入口，测验/等级仍独立。播放结束只记录客户端报告，不等于认证完课。实际媒体SHA变化时旧位置视为0，下次保存更新媒体版本。
- 初次实现曾把秒数按任务隔离；自审发现与产品手册不符后新增0005前向迁移修正，不改写已部署的0004，不用修改产品基线来掩盖错误。
- 业务成功事件与业务事务一起写；接口错误不冒充成功。真实微信播放、正式题库和教学媒体继续待外部条件。

本文件是已有规则的实现细化，完成与测试结果另记审查及测试登记。
