# M7行为分析实现约束（已暂停，规则初稿）

**2026-10-18状态：**按用户要求暂停后续开发，保存当前代码并推送。当前只有事件白名单整理、统计规则纯函数和9项规则测试；尚未接入采集队列、API、数据库聚合任务或Pro报表页面。以下为既有开发约束，不代表功能已交付。

基准`6ee602c`。仅实现现有D07和MT129–138，不新增登录、外部统计SDK或数据外发。后台保持官方Ant Design Pro。

- 成功成绩/分析/任务/等级/标记由服务端事务记录；客户端只上报允许的行为，不接受visitorId、environment、sessionId、JD或任意properties。个人资源上下文必须属于当前访客，服务端决定环境和session。
- UTC存储、北京时间自然日；session接收活动空闲30分钟更新，跨午夜不切。客户端时间超出接收时间±24小时，标异常并以接收时间分桶。
- 每批1–50条，eventId去重；同ID不同内容不覆盖。客户端队列最多200条、24小时；失败退避且有自动重试上限，失败不阻断学习。普通video_progress每15秒最多一次，暂停/结束另报位置；位置跳跃不等于可信观看时长。
- 漏斗按访客/flow/任务顺序和入口起24小时，边界含24小时整。岗位前两步属flow，选多个任务时展开为多条任务链；尚未选任务的flow暂计一条待选链。报表分别给链数、flow数、访客数，不能混用分母；按入口日归属。任务漏斗从该任务选择起算，两入口分开。
- 日聚合保留去重成员集合以便区间访客取并集，不把每日去重人数直接相加。D1/D7只计算到达观察日的首学队列，未来观察日为待观察，不写成流失。
- 默认正式环境过滤，local/test/demo需显式选择；客户端上报播放和手动看过分列。没有人工评审就返回未评审，不生成通过率。
- 行为原始90天、请求14天、日聚合365天；删除原始记录前先完成所需聚合。不把分析数据保留期用于删除任务、题目快照、成绩、位置、标记或发布审计。P50/P95使用可用原始样本与明确窗口，不平均每日百分位。

接口、迁移、采集队列、统计规则及Pro页面同时配测试；完成状态和执行证据后续记入M7审查。
