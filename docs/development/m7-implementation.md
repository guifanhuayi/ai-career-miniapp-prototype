## 本次实现

- `POST /api/v1/events`：访客鉴权、1–50条原子批次、严格事件白名单、未知/敏感字段拒绝、归属校验、同ID同内容去重和异内容409。flow/任务/场景从本人业务资源推导，环境与session由服务端生成。被15秒限频的视频位置仍保留去重身份，但不进入行为统计。
- `GET /api/v1/admin/analytics`：仅本机管理；默认production，可显式选择local/test/demo；最近365个北京时间自然日。岗位和直接任务入口分别统计，输出链数、flow数、访客数；内部集合不返回客户端。
- 客户端统一队列：最多200条、24小时过期、每批50、失败退避、每轮最多5次失败重试；前台恢复可重开一轮。丢响应重发原eventId；无效事件逐条隔离，避免丢掉同批有效事件；存储/采集故障不阻断业务。按本机访客凭据分区，换身份不能把旧队列发给新访客。浏览器独立演示模式不采集到正式API。
- 全部正式页面曝光；岗位/截图确认、场景、推荐、课程详情、打开、播放/暂停/位置/结束、学习恢复接入。测验/分析成功、任务选择、切级、手动看过仍由业务事务唯一记录。首次选择任务不误计恢复；卡片与播放器原生按钮均可观测，定制播放按钮不重复计打开。
- 迁移0006：事件版本/位置/异常/内容指纹/标记字段、访客首次学习时间与采集索引。首次学习时间从旧成功事件回填，后续以最早有效学习日更新；不会因90天删除原始行为而把老访客当新访客。
- 启动及每小时聚合/清理；数据库事务锁避免多个清理实例互相覆盖。日聚合保留学习访客与漏斗集合以跨日取并集；原始行为90天、请求14天、聚合365天。清理边界日先做完整快照并封存，重复清理不从剩余半天原始数据覆盖完整统计；不删除业务记录。
- Pro `/analytics`：环境与日期、日/7日活跃、双入口漏斗、D1/D7、课程与场景/任务分布、时钟/位置异常、请求质量、脱敏规则分析概况。今日留存标观察中，未来观察日为待观察；P50/P95只来自明确的可用原始窗口，零样本返回null。
- 质量口径：本地规则与模拟题/测试片明确标注；语义/人工质量显示未评审，不伪造通过率或可信学习时长。
