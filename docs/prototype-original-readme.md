# 百年前程 · AI成长课 小程序交互原型

在线体验：https://guifanhuayi.github.io/ai-career-miniapp-prototype/

首页默认平铺所有15个页面与状态，支持适应宽度、全部适应、5%–120%缩放，点击任一页面可进入对应交互原型。

单页交互入口：https://guifanhuayi.github.io/ai-career-miniapp-prototype/prototype.html

全部页面总览：https://guifanhuayi.github.io/ai-career-miniapp-prototype/overview.html

通过 GitHub Pages 发布 `main` 分支的根目录，推送更新后自动部署。

原型依据：用户提供的飞书《大学生AI学习小程序demo》，2026-10-17阅读。
原文：https://mcn6gipq7cmq.feishu.cn/wiki/KCvbwClxuiGUUDk8rfGc35vfnde

产品定位：内嵌百年前程职业规划平台，为希望提高实习和求职竞争力的大学生提供任务导向、分层次的AI课程视频推荐。

本期：岗位JD文本/截图输入、AI能力需求匹配、17类场景及具体任务选择、能力测验、初/进/高阶课程、短视频/系统课推荐和点击直接打开外部视频。补充页面均服务以上闭环。

排除：AI内容创作/写作/生图/生视频工具、短剧变现、学生上传或出售课程、驻场收费、支付、论坛。图片视频生成是学习场景，不是平台内置生成工具。

运行：双击 prototype.html 即可单文件离线体验。overview.html 为15页面总览。也可以在本目录运行 `python -m http.server 8765 --bind 127.0.0.1` 后访问 http://127.0.0.1:8765 。无依赖。修改源文件后运行 `python build.py` 更新单文件及压缩包。

画布：393×852 CSS像素的iPhone竖屏参考尺寸；非某一具体机型的像素规格。包含状态栏、微信胶囊和底部安全区。

原型范围：页面和流程可交互，数据仅在内存中；刷新重置。JD文本按关键词匹配，截图OCR为可编辑的示例；测验为每场景4道演示题，不代表经过验证的能力量表；课程标题、时长及更新批次均为示例，不是假装已核验的视频。点击课程按钮或封面播放入口后直接在当前窗口打开外部视频，无确认页。所有示例课程暂共用已核对的B站视频链接 https://www.bilibili.com/video/BV1Ey756nEL5/ ，此片源仅演示跳转流程，后续需逐课替换。不连接真实模型、账号或微信服务。示例视频的实际播放及登录要求由外部平台决定。

首页三种布局：?variant=guide（引导式）、?variant=task（任务式）、?variant=editorial（目录式）。仅首页结构不同，共用完整业务闭环。

总览页面通过 ?screen= 页面参数打开相互独立的演示状态。普通入口没有预置学习路径。

源码入口：`overview.html` 是平铺总览，`prototype-source.html` 是单页交互原型模板。运行 `python build.py` 后生成总览首页 `index.html` 和离线交互文件 `prototype.html`，并同步项目压缩包。

验收记录：脚本语法检查通过；在浏览器人工走通JD文本示例、截图示例及核对、岗位关键词与原文证据匹配、PPT任务选择、四道测验、分级推荐、等级切换、视频时长筛选、课程详情及外部视频直接跳转。检查了首页、测验结果、课程推荐和总览的实际渲染。

主要页面：首页、岗位输入、截图文字确认、分析中、能力分析、场景目录、任务选择、能力测验、测验结果、分级学习路径、课程详情、我的学习、空态、搜索无结果。

原型问题：用户能否从“目标岗位/想完成的任务”自然找到适合当前能力的视频课程？
